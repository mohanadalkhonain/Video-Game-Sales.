# Video-Game-Sales.

## Data analysis (Member 2)

- `src/analysis.py`: the `SalesAnalysis` base class and its `GenreSummary` and `RegionalComparison` subclasses (pandas + NumPy).
- `run_analysis.py`: answers Q1–Q3 on `data/processed/vgsales_cleaned.csv`.
- `compare_before_after.py`: compares the results on the raw and the cleaned data.
- `outputs/analysis_reports/analysis_report.md`: results and findings.
- `outputs/analysis_reports/work_log.md`: a step-by-step record of how the analysis was built.

```bash
pip install pandas numpy
python run_analysis.py
python compare_before_after.py
```
